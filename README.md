# System Sculptor

A Python project for generating and editing architecture blueprints.

## Usage

1. Create a new instance of the `SystemSculptor` class.
2. Load a Mermaid source diagram using the `load_diagram` method.
3. Edit the diagram by adding, removing, or renaming nodes using the `add_node`, `remove_node`, and `rename_node` methods.
4. Save the edited diagram using the `save_diagram` method.
5. Export the edited diagram as a Mermaid source string using the `export_diagram` method.

## Testing

Run the tests using `pytest` to ensure the implementation is correct.
