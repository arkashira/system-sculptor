# Partner Targets

## Integration Roadmap

### Phase 1: Immediate (0-3 months)
1. **GitHub**
   - **Rationale**: GitHub is the most widely used platform for software development, making it a natural fit for a tool that analyzes and optimizes software architecture.
   - **Free-tier limits**: Unlimited public repositories, 500MB storage for private repositories.
   - **Integration effort**: S
   - **Value-add**: Automatically analyze repositories for architecture issues and suggest optimizations.
   - **Affiliate/revenue-share**: Yes

2. **GitLab**
   - **Rationale**: GitLab is another popular platform for software development, especially among enterprises.
   - **Free-tier limits**: Unlimited public and private repositories, 5GB storage.
   - **Integration effort**: S
   - **Value-add**: Provide architecture analysis and optimization suggestions within the GitLab CI/CD pipeline.
   - **Affiliate/revenue-share**: Yes

### Phase 2: Short-term (3-6 months)
3. **SonarQube**
   - **Rationale**: SonarQube is a widely used tool for continuous inspection of code quality, making it a good complement to System Sculptor.
   - **Free-tier limits**: Community edition is free for open-source projects.
   - **Integration effort**: M
   - **Value-add**: Combine code quality metrics with architecture analysis for a comprehensive view of system health.
   - **Affiliate/revenue-share**: No

4. **Jira**
   - **Rationale**: Jira is the leading project management tool for software development teams.
   - **Free-tier limits**: Free for up to 10 users.
   - **Integration effort**: M
   - **Value-add**: Create and track architecture-related tasks and issues directly in Jira.
   - **Affiliate/revenue-share**: Yes

### Phase 3: Medium-term (6-12 months)
5. **Docker Hub**
   - **Rationale**: Docker Hub is a popular registry for container images, and integrating with it can help analyze containerized applications.
   - **Free-tier limits**: 1 private repository, 200MB storage.
   - **Integration effort**: L
   - **Value-add**: Analyze container images for architecture issues and suggest optimizations.
   - **Affiliate/revenue-share**: No

6. **AWS CodeCommit**
   - **Rationale**: AWS CodeCommit is a fully-managed source control service that integrates well with other AWS services.
   - **Free-tier limits**: 50GB-month of storage.
   - **Integration effort**: L
   - **Value-add**: Provide architecture analysis and optimization suggestions for repositories hosted on AWS CodeCommit.
   - **Affiliate/revenue-share**: Yes (through AWS Partner Network)

### Phase 4: Long-term (12+ months)
7. **Azure DevOps**
   - **Rationale**: Azure DevOps is a set of development tools provided by Microsoft, including Git repositories, build and release pipelines, work item tracking, and more.
   - **Free-tier limits**: 5 users, unlimited private repositories.
   - **Integration effort**: L
   - **Value-add**: Integrate with Azure DevOps pipelines to provide architecture analysis and optimization suggestions.
   - **Affiliate/revenue-share**: Yes (through Microsoft Partner Program)

8. **Bitbucket**
   - **Rationale**: Bitbucket is a Git repository management solution that is widely used by development teams.
   - **Free-tier limits**: Unlimited private repositories for up to 5 users.
   - **Integration effort**: M
   - **Value-add**: Provide architecture analysis and optimization suggestions for repositories hosted on Bitbucket.
   - **Affiliate/revenue-share**: Yes
